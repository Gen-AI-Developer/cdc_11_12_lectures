| Field    | Meaning                          | Includes                       |
| -------- | -------------------------------- | ------------------------------ |
| **real** | Actual elapsed (wall-clock) time | Waiting + CPU + I/O            |
| **user** | CPU time in **user mode**        | Your code execution            |
| **sys**  | CPU time in **kernel mode**      | System calls (I/O, memory ops) |
